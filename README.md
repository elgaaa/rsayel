# Rsayel UI clone

Responsive front-end recreation based on the supplied Rsayel screenshots.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Included
- Mobile-first layout matching the screenshots: status strip, top navigation, dark sidebar, profile form, dashboard cards, dropdown menu.
- Working sidebar navigation, user dropdown, responsive mobile drawer, dark mode, and demo form interactions.
- Dashboard, profile, chat, numbers, received SMS, test panel, statistics, credit notes, payment requests, users, agents, notifications, and activity views.

## Important
This is a UI prototype, not a working SMS service. Login, SMS sending, account data, notifications, user records, and password changes need a real backend/API. Do not use it to collect real passwords or personal information until authentication, server-side validation, secure storage, and authorization are implemented.
